# 《裂界战线》宽战区 PVE 网页原型

版本：**V1.5.0**  
类型：离线单机、宽区域实时战斗、单一随机牌库、全新十关剧情、扩展肉鸽远征

## 启动方法

1. 完整解压 ZIP，不要只把 `index.html` 单独拖出来。
2. 双击根目录中的 `index.html`。
3. 推荐使用最新版 Chrome、Edge 或 Firefox。

游戏不依赖网络、服务器、npm、安装程序或第三方框架。全部脚本、图片、样式与音效逻辑均已包含在压缩包内。

少数公司或学校电脑可能通过浏览器策略限制本地脚本。遇到这种情况，可以在游戏目录打开终端并运行：

```bash
python -m http.server 8000
```

随后访问：

```text
http://localhost:8000
```

## V1.5.0 核心变化

### 1. 单位寻路与索敌重制

本版将战斗单位改成更接近竞技场式自动战斗的逻辑：

- 每类单位拥有独立的**索敌半径**与**攻击距离**；
- 单位发现目标后会持续锁定，不再每帧反复换人；
- 只有目标死亡、隐匿、超出追击距离或无法抵达时才重新索敌；
- 单位明确区分地面、空中、全部目标、只攻击部队与只攻击建筑；
- 攻城单位会无视普通部队并前往建筑或核心；
- 防御建筑与诱导建筑可以将建筑猎手拉向中央，制造交叉火力；
- 没有近处目标时，单位会按部署点接入最近桥梁，并向对应前哨推进；
- 地面单位采用网格短路径绕过障碍、建筑和大型单位；
- 轻型单位会给重型单位让路，桥口允许适度压缩通行；
- 飞行单位和相位单位拥有不同的障碍处理方式；
- 远程刺客、建筑猎手等单位还拥有额外目标偏好。

第一关就是新的索敌与建筑牵引教程。

### 2. 十关剧情全部替换

旧十关已经替换为全新的 **“影渊篇”**：

1. 桥头诱饵
2. 猎犬过桥
3. 隐幕丛林
4. 三岔误导
5. 王塔试炼
6. 灵魂市集
7. 折跃狩场
8. 日蚀蜂巢
9. 影渊合唱
10. 最后的桥

新战役重点围绕这些机制展开：

- 防御建筑牵引建筑猎手；
- 隐匿单位绕开远距离索敌；
- 三桥地图中的诱导建筑；
- 强制换路与目标重置；
- 全路裂隙门与攻城浪潮；
- 日蚀、灵魂抽取和多阶段终局Boss。

同时新增四张地图：

- 时砂双桥
- 影渊三岔迷宫
- 月蚀回廊
- 终末王桥

### 3. 新阵营：影渊教团

影渊教团的关键词是：**诱导、隐匿、建筑猎杀、目标标记与相位穿越**。

主要卡牌包括：

- 裂隙猎犬：只攻击建筑，可被防御建筑牵引；
- 幽铠守望者：高仇恨前排，吸引附近敌军；
- 灵能司祭：优先攻击远程、治疗与攻城单位；
- 帷幕后行者：短暂隐匿，擅长猎杀后排；
- 相位掘行兽：能够穿越普通地形障碍；
- 诱导方尖碑：高优先级牵引建筑；
- 噩梦裂隙门：持续生成攻城猎犬；
- 日蚀帷幕：让友军隐匿并清除敌方锁定；
- 灵魂猎印：提高区域敌军受到的伤害；
- 蚀界执政官：护盾、范围攻击、吸血与首次接敌狂热。

阵营被动“灵能渗透”会提高全军索敌范围，并让单位第一次锁定目标时获得短暂狂热。

### 4. 肉鸽远征扩展

八层Boss远征保留原有“12张初始卡组 + 战后奖励三选一”，并新增：

- 四个可选阵营；
- 每层三个随机Boss与不同战区异变；
- 中后期每层固定出现一个精英悬赏Boss；
- Boss胜利后获得裂界碎片；
- 常驻裂界商店；
- 购买战利品重掷；
- 购买随机遗物；
- 永久移除一张远征卡牌；
- 卡牌锻造系统；
- 同一张牌最多锻造两次；
- 第二次锻造会额外降低1点费用；
- 第2、4、6层后的营地事件；
- 免费锻造、休整精简、重新侦察与危险契约；
- 危险契约会同时给予高价值奖励与永久诅咒；
- 精英Boss会提高特殊战利品概率并额外奖励碎片。

### 5. 新Boss能力

影渊Boss拥有新的规则型能力：

- 诱导劫持：在中央生成高优先级方尖碑并清除锁定；
- 灵魂什一税：伤害全体友军并治疗Boss；
- 王桥易位：将最强友军折跃到另一通路；
- 黑日幕墙：敌军隐匿并重置索敌；
- 万门齐开：所有通路生成噩梦裂隙门；
- 唯一目标：轮流发动牵引、换路、隐匿与吸血。

## 基础操作

| 操作 | 方式 |
|---|---|
| 拖动部署 | 按住手牌，拖到蓝色战区后松开 |
| 点击部署 | 点击手牌，再点击战场落点 |
| 归档手牌 | 右键手牌，或选中后按 `R` |
| 选择手牌 | 数字键 `1` 至 `0` |
| 暂停或继续 | `Space` |
| 撤离战斗 | `Esc` |
| 调整速度 | 点击战斗右上角速度按钮 |

## 战斗节奏

- 起始费用：5；
- 默认费用上限：10；
- 试探期：每2.8秒恢复1费；
- 桥头交锋：费用恢复速度提高到2倍；
- 王桥决战：费用恢复速度提高到3倍；
- 基础抽牌间隔：5.6秒；
- 手牌上限：10；
- 归档次数：默认2次；
- 牌库耗尽：8.4秒后完成重洗。

## 存档说明

V1.5.0 使用新的浏览器本地存档键，因此不会与旧版战役进度混淆。设置界面仍可导出和导入存档码。

清理浏览器站点数据会删除本地进度。

## 原型边界

当前版本仍是纯前端PVE原型，不包含联网PVP、服务器账号或付费系统。数值平衡、Boss能力频率和部分卡牌组合仍可继续调整，但十关战役、标准套牌和完整八层远征均可运行。

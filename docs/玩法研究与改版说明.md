# V1.4.0 玩法研究与改版说明

## 一、寻路与索敌参考方向

本版没有逐像素复刻某一款游戏，而是提取王冠竞技场类实时战斗中最有策略价值的几个规则：

1. **目标类别明确**：普通部队、空中单位与只攻击建筑的攻城单位拥有不同目标集合；
2. **锁定具有持续性**：单位不会每一帧重新挑选最近目标，而是在目标死亡、隐匿或脱离追击范围后重新索敌；
3. **建筑可以改变军路**：中央防御建筑能吸引建筑猎手，形成牵引、拉扯和交叉火力；
4. **桥梁与缺口决定宏观路径**：单位先选择可通行路线，再在局部使用短路径绕开障碍和建筑；
5. **嘲讽与强制位移属于高级规则**：它们直接修改单位的目标或通路，因此必须拥有明显视觉反馈。

Supercell 的官方更新资料中明确区分了可攻击空中和地面的炮塔，也展示了“嘲讽附近敌人并将其吸引来攻击自己”以及把单位扔到另一条线路的能力。这些公开规则证明，目标类别、诱导仇恨与换路本身就可以成为一层独立策略，而不只是后台 AI 细节。

## 二、本项目的寻路实现

《裂界战线》需要适配更宽的自由部署区域，因此采用了“宏观通路 + 局部 A*”的混合结构：

- 玩家落点决定单位首先接入哪条桥梁或通路；
- 没有近处敌人时，单位沿当前通路向前哨和核心推进；
- 发现有效目标后，单位进入粘性锁定状态；
- 地面单位缓存一条短路径，绕开静态地形、建筑和堡垒；
- 防御建筑、嘲讽单位和高仇恨目标会影响索敌评分；
- 建筑猎手无视普通部队，但仍会被其他建筑牵引；
- 飞行单位忽略地面障碍，相位单位则拥有特殊穿越规则；
- 单位质量影响桥口挤压，重装单位可以推动轻型友军让路。

这样既保留“大范围自由放兵”的感觉，又让中央两路、三路通道真正成为可争夺的地形，而不是画在背景上的装饰线。

## 三、肉鸽参考方向

《炉石传说》Dungeon Run 的官方设计使用 10 张初始牌组、8 场随机遭遇和 48 种可能敌人；每次胜利后，玩家可以从主题三卡包中扩充牌组，并偶尔获得明显超规格的宝藏。其价值不只是内容随机，而是让每次奖励都改变后续抽牌概率和构筑方向。

## 四、V1.4.0 的肉鸽扩展

本项目继续使用“12 张起步、8 层 Boss、每战三选一”作为骨架，并补上更完整的中期经营层：

- 每层从三名 Boss 中选择一名；
- 中后期固定出现一个精英悬赏 Boss；
- Boss 胜利后获得裂界碎片；
- 常驻商店提供重掷、随机遗物、删牌与卡牌锻造；
- 同一卡牌最多锻造两次；
- 第二次锻造会降低 1 点费用；
- 第 2、4、6 层后出现营地事件；
- 营地可免费锻造、精简牌库、重新侦察，或签下带有永久诅咒的高风险契约；
- 精英 Boss 保证更高的碎片收益，并提高遗物或主动宝藏出现率。

这使远征不再只是“打完一关拿三张牌”，而是同时经营牌库厚度、关键牌强度、碎片经济、诅咒风险和 Boss 路线。

## 五、新阵营：影渊教团

影渊教团专门围绕新版索敌系统设计：

- **裂隙猎犬**只攻击建筑，是建筑牵引规则的直接载体；
- **幽铠守望者**拥有高仇恨和嘲讽半径；
- **灵能司祭**优先猎杀治疗、远程和攻城后排；
- **帷幕后行者**用隐匿使远距离敌人失去锁定；
- **相位掘行兽**能穿过普通地形；
- **诱导方尖碑**以极高仇恨改写附近敌人的军路；
- **噩梦裂隙门**持续制造建筑猎手；
- **日蚀帷幕**清除敌方锁定并让友军隐匿；
- **灵魂猎印**放大区域目标所受伤害；
- **蚀界执政官**把护盾、范围伤害、吸血和首次接敌狂热结合在一起。

这个阵营的乐趣不是纯粹数值更高，而是让玩家直接操作“敌人下一步准备打谁”。

# V1.6.3 影渊单位与建筑动画一致性说明

## 1. GPT Image 2 生成规格

本次通过内置 imagegen（GPT Image 2）为 9 个影渊单位生成独立 2×2 动作图。每张图严格使用同一个角色参考，四格顺序统一为：

```text
待机 | 移动
攻击 | 收势
```

共同提示规格：透明 1:1 画布、正交三分之四侧视、统一相机/比例/落脚点、角色完整入框；动作只改变姿势和紧凑攻击特效，不允许改造身体、服装、武器、配色或渲染风格。窥视之眼与最终 Boss 的首轮结果带有不透明背景，因此从原始角色参考重新生成，最终像素检查确认空白角落 Alpha 为 0。

| 单位 | 动作重点 |
|---|---|
| 裂隙猎犬 | 警戒、奔跑、爪击撕咬、回收 |
| 幽铠守望者 | 持盾、重步、盾击、架盾 |
| 灵能司祭 | 施法待机、悬浮、法杖射击、回收 |
| 帷幕后行者 | 潜伏、冲刺、双刃交叉斩、低姿回收 |
| 相位掘行兽 | 盘踞、相位爬行、咬击触须、回缩 |
| 蚀界执政官 | 悬浮、滑行、灵能球、施法回收 |
| 窥视之眼 | 悬浮、推进、镜头束流、降能 |
| 裂界幽魂 | 剑势、相位冲刺、能量斩、跪姿回收 |
| 影渊君王 | 重型待机、迈步、双拳地击、站立回收 |

生成源图保存在 `assets/source_sprites_gptimage2/`。`tools/build_consistent_animations.cjs` 使用每张图四格透明像素的共同边界完成统一裁切，再输出游戏读取的 `assets/sprite_sheets_runtime/shadow.png` 与 `shadow_boss.png`。

## 2. 建筑一致性策略

旧建筑图集的四帧分别由模型重绘，炮管、底座、根系、晶体数量和主体外轮廓会跨帧变化。本次将每张图的第一帧作为几何基准，后续三帧复用同一主体，只逐步增加亮度、饱和度、能量核心光晕与激活光环。

这样仍保留“静止 → 启动 → 强化 → 完全激活”的节奏，但不再让建筑像换了一栋。21 张建筑、核心与前哨图集全部使用同一确定性流程重建。

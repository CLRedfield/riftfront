# V1.6.0 美术资源接入说明

## 1. 缩略图读取顺序

UI 使用以下优先级读取卡牌图像：

```text
RF.THUMBNAIL_ART[card.id]
→ card.art
→ RF.CARD_ART[card.id]
→ 文字符号图标
```

这使新的卡牌缩略图不会干扰战场单位原有的序列帧或兼容贴图。

## 2. 建筑动画格式

`assets/building_animations/*.png` 均为横向四帧图集：

```text
总尺寸：1280 × 320
单帧：320 × 320
顺序：静止 → 启动 → 强化 → 攻击/完全激活
```

炮塔攻击时直接使用第4帧；其他建筑按照角色类型播放环境循环。

## 3. 运行时映射

`js/v160_visual_patch.js` 中包含：

- `THUMBNAILS`：全部单位和建筑卡牌缩略图路径；
- `BUILDING_ANIMATIONS`：17种卡牌建筑动画路径；
- `FORT_ANIMATIONS`：玩家/敌方核心与前哨动画路径；
- `drawBuildingSprite` 补丁：按建筑职责与攻击状态选择帧；
- `drawFort` 补丁：以生成式建筑图集替换旧几何核心和前哨。

## 4. 资源预览

- `assets/previews/v160_unit_thumbnail_atlas.webp`
- `assets/previews/v160_building_atlas.webp`

两张总览图用于快速核对是否有漏图、错位或阵营配色异常。

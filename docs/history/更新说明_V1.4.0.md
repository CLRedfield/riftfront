# 《裂界战线》V1.4.0 更新说明

## 战斗AI重制

- 新增独立索敌半径与攻击距离；
- 新增持续目标锁定与追击距离；
- 新增地面、空中、全部、只部队、只建筑等目标类别；
- 建筑猎手现在会被防御建筑牵引；
- 新增目标优先级，如后排猎杀、低生命目标、高仇恨目标；
- 无目标时按部署点接入最近桥梁与对应前哨；
- 地面单位采用网格A*短寻路绕过障碍与建筑；
- 新增单位质量、挤压、推让与桥口通行；
- 飞行与相位单位使用不同寻路规则。

## 全新十关

原有十关替换为完整的“影渊篇”，包括4张新地图、全新对白、敌人组合、关卡目标、环境机制和最终Boss。

## 新阵营：影渊教团

新增10张阵营卡和1张敌方Boss卡，核心玩法包括建筑诱导、隐匿刺杀、相位移动、持续召唤与目标标记。

## 肉鸽扩展

- 新增精英Boss；
- 新增裂界碎片；
- 新增常驻商店；
- 新增随机遗物购买；
- 新增牌库精简；
- 新增卡牌锻造；
- 新增第2、4、6层营地事件；
- 新增危险契约与永久诅咒；
- 新增影渊生态区、主题卡包、遗物和主动宝藏。

## 兼容性

- 继续保持纯前端离线运行；
- 继续支持双击 `index.html` 启动；
- V1.4.0 使用独立本地存档键。

# 《裂界战线》V1.3.0 更新说明

## 牌库重构

- 删除先锋、应变、决胜三个补给组。
- 标准模式改为单一30张随机牌库。
- 起始手牌调整为5张。
- 套牌编辑器改为30个统一槽位。
- 教程、作战手册、战斗HUD和重洗提示同步修改。

## 肉鸽远征重构

- 远征长度从5战扩展为8名Boss。
- 开局选择阵营与12张初始牌组。
- 每战后进行一次三选一：
  - 3张主题卡包；
  - 被动遗物；
  - 主动宝藏卡。
- 第1、3、5、7层保证出现特殊战利品。
- 每轮拥有1次战利品重掷。
- 新增完整牌库查看界面与8层路线进度条。
- 进入战斗前新增Boss档案界面。

## 阵营与卡牌

- 钢铁联邦：圣盾、工程、空骑、磁轨重装。
- 孢潮母群：低费增殖、吸血、治疗、世界根巨兽。
- 棱镜盟约：远程、相位、冻结、换线与高价值法术。
- 当前共58张标准玩家卡牌与12张主动宝藏卡。

## Boss能力

新增或扩充15种周期性Boss能力，包括冻结全场、手牌加费、全通路暴雪、引力井、陨石锁定、全通路岩浆、敌方自修、抽牌封锁、镜像复制与吞噬牌库等。

## 美术

- 新增5张大幅主视觉；
- 新增15种单位贴图；
- 新增4种Boss贴图；
- 贴图用于卡牌库、手牌和战场单位；
- 全部资源以WebP本地加载。

## 技术与测试

- 战斗引擎支持单一牌库重洗。
- 新增Boss周期能力调度器扩展。
- 新增主动宝藏法术效果。
- 第一关教程自动适配单一牌库。
- 使用自动化脚本完整模拟8层远征通关。

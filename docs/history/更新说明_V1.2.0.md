# 裂界战线 PVE 网页原型 V1.2.0 更新说明

## 本版重点

1. **套牌系统重做**
   - 去掉“先锋 / 应变 / 决胜”三组补给的区分。
   - 改为 **单一 30 张战术牌库**，战斗中从整个牌库随机抽牌。
   - 套牌构筑界面同步改版，直接编辑整套 30 张牌。

2. **肉鸽模式重做**
   - 参考“狗头人冒险”思路，开局先选择阵营与 **12 张初始卡组**。
   - 每过一关，都会出现 **3 组选项**，从中选择 1 组带入后续战斗。
   - 奖励可能是：
     - 3 张新卡组成的卡包；
     - 1 件只在本轮生效的遗物 Buff。
   - 本轮远征共 5 场战斗，最终挑战终极节点。

3. **不同阵营**
   - 新增三种远征阵营：
     - 钢铁联邦
     - 孢潮母群
     - 棱镜盟约
   - 每个阵营都有独立的开局美术、初始卡组风格与被动效果。

4. **Boss / 战区机制更鲜明**
   - 每个远征选项都会显示“主宰能力 / Boss 能力”。
   - 不同生态战区会拥有不同的强化方向，如更高频的环境机制、更强前哨、更快后勤等。
   - 每场远征战斗都包含一名战区主宰登场。

5. **美术升级**
   - 新增 AI 生成的首页主视觉。
   - 新增三张阵营立绘。
   - 新增远征模式主视觉图。
   - 让菜单、远征选择与整体氛围更接近成品感。

## 已知说明

- 本版仍为网页原型，主要验证“大区域放兵 + 通路汇入 + 卡组构筑 + 肉鸽成长”的核心循环。
- 部分数值仍可继续打磨，例如：
  - Boss 强度曲线；
  - 卡包奖励的平衡性；
  - 阵营间被动差异；
  - 个别卡牌的费用与强度。
- 剧情战役仍保留原有框架，主要升级集中在套牌与肉鸽远征部分。

## 启动方法

直接双击 `index.html` 即可运行。
如果本机浏览器限制本地脚本，也可以使用任意本地静态服务器打开。

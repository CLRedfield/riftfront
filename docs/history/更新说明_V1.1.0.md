# V1.1.0 更新说明：宽战区重构

## 战场

- 将固定双线战场重构为宽区域二维战场。
- 新增10张地图布局，中央通路数量随地图在2条与3条之间变化。
- 己方半场支持大范围自由部署。
- 单位穿越中央区域时沿通路寻路，进入开阔区域后可跨方向追敌。
- 新增矩形与圆形障碍物、视线阻挡、局部避障和友军分离移动。
- 前哨数量会自动匹配地图通路数量。
- 肉鸽模式会随机选择对应生态的战场布局。

## 操作

- 新增手牌拖动释放。
- 新增浮动卡面、合法与非法落点反馈、最近通路提示和失败原因提示。
- 保留点击选牌与点击战场的备用操作方式。

## 视觉

- 重绘步兵、无人机、生物、重型载具、建筑与Boss的Canvas矢量造型。
- 新增朝向、步行动画、飞行浮动、炮口闪光、护盾、冻结与集结状态反馈。
- 重绘中央通路、自由部署区域、前沿投送带和生态障碍物。

## 保留内容

- 10关剧情战役
- 简化肉鸽远征
- 30张套牌与三个补给组
- 每2.8秒恢复1费、每5.6秒抽牌
- 1倍、2倍、3倍战斗阶段
- 套牌编辑、本地存档与存档码导入导出
